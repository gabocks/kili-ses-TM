# kili-ses-TM
Function (kilanttrify) that creates gantt charts customized for the task management of the Kili-SES project (https://kili-ses.senckenberg.de/). It is also embedded into a shiny app that is deployed here:  https://gbocskberger.shinyapps.io/kili-ses-tm/. Those scripts are heavily based on ganttrify and shinyganttrify from Giacomo Comai (https://github.com/giocomai) .
